Teanga
Fólder fréimhe do phríomhleabharlann breiseán # nó an suíomh ina stórálann tú do chuid pacáistí deiridh le dáileadh. # Úsáidtear é seo mar an t-eolaire tosaigh do Filechoose.
Eolaire uigeachtaí do thionscadail Blender (nó an tionscadal atá á oibriú agat). # Seo an t-eolaire ina stóráiltear uigeachtaí do mhúnla mar chomhaid PNG.
Comhad in-fhorghníomhaithe "NVIDIA Texturetool". # Tá sé seo éigeantach agus is gá é chun uigeachtaí a thiontú ó fhormáid insamhalta ar bith go PNG. # Is é an cosán réamhshocraithe ná C:/Program Files/NVIDIA Corporation/NVIDIA Texture Tools/nvtt_export.exe.

Ní féidir an réimse a chur in eagar.
Fólder fréimhe SDK MSFS. # Má tá ImageToMSFSKTX2 in úsáid agat cheana, iompórtálfar é seo freisin nuair a chliceálann tú ar an gcnaipe 'Iompórtáil'. # Tá an SDK éigeantach má tá tú ag obair ar thionscadail a úsáideann an fhormáid KTX2, mar ní oibríonn íomhánna a tiontaíodh le huirlis NVIDIA sa tsamhail. # Is é an réamhshocrú ná C:/MSFS 2024 SDK
An siopa atá á úsáid agat. # Microsoft nó Steam. # Is é Microsoft an réamhshocrú.
An fhormáid uigeachta a úsáideann do thionscadal in MSFS2024. # DDS nó KTX2. # Ríomhtar an luach seo go huathoibríoch ó eolaire uigeachta an phacáiste.
Na cineálacha uigeachta ar mian leat a chur san áireamh sna tiontuithe. # Is féidir le pacáistí MSFS go leor uigeachtaí a bheith iontu, agus de ghnáth ní oibrímid ach le comhaid # albeide (ALBD) agus comhdhéanta (COMP). # I bhformhór na gcásanna, ba cheart duit ALBD agus COMP a roghnú dá bhrí sin. # Mura n-úsáideann do thionscadal dathanna miotalacha, is féidir leat ALBD amháin a roghnú go sábháilte.
